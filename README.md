# agents-for-humanity-submission
Submission repo for the agents of humanity hackathon

# Installation
Clone the repository to your machine.

Create a virtual environment and download the required libraries:

    python3 -m venv .venv

    source .venv/bin/activate

    pip install -r my_agent/requirements.txt


Set API key as environment variable:

Create a file called .env in the my_agent directory

In the file, insert the following: 

    API_KEY=<your api key>
